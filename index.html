nx-auto-mcp

Siemens NX MCP Server for AI-Driven CAD Automation

nx-auto-mcp lets AI assistants drive Siemens NX directly via the Model Context Protocol. It exposes 130+ CAD tools (modeling, sketching, assembly, measurement, inspection, sheet metal, and more) as MCP tools, callable from Claude Code, Cursor, or any MCP client.

  • GitHub: https://github.com/cyw2527/nx-auto-mcp
  • Keywords: Siemens NX MCP, NX MCP Server, NXOpen, CAD automation, AI agent, Model Context Protocol
  • Architecture: MCP stdio adapter (Node.js) → TCP 1977 → NX plugin (C# / NXOpen)
  • Latency: 10–50 ms per tool call (resident process, no journal startup overhead)

Why nx-auto-mcp?

🏎️ Low Latency

10–50 ms per tool call. TCP resident process stays alive — no journal startup overhead.

Quick Start

# Clone the repository
git clone https://github.com/cyw2527/nx-auto-mcp.git
cd nx-auto-mcp

# Build and deploy (requires NX installed)
cd plugin
.\build.bat run

# Run setup
.\setup.bat

# Add to your MCP config (.mcp.json)
{
  "mcpServers": {
    "nx": {
      "command": "node",
      "args": ["path/to/nx-auto-mcp/mcp/nx-exec-mcp.js"]
    }
  }
}

Tool Coverage

  • Modeling / solids: 24 tools (extrude, revolve, sweep, blend, chamfer, hole, pattern, boolean, shell, draft, loft, etc.)
  • Sketching: 18 tools (create/edit sketches, constraints, dimensions, readback)
  • Assembly: 14 tools (add component, create component, find same bodies, component tree, fix/unfix)
  • File operations: 8 tools (open, close, save, create part, import/export)
  • Inspection / topology: 7 tools (face analysis, edge analysis, feature tree, XT export)
  • Measurement: 7 tools (distance, angle, volume, mass properties, area, perimeter)
  • Synchronous modeling: 6 tools (move, offset, resize, replace face)
  • Surfaces: 5 tools (extrude surface, revolve surface, sweep surface, bridge)
  • Utilities: 12 tools (undo, screenshot, journal execution, view control, probe builder)
  • Display: 4 tools (show/hide, layer control, view orientation)
  • Datum: 4 tools (datum plane, datum axis, datum CSYS)
  • Correction: 4 tools (face correction, edge correction)
  • Sheet metal: 3 tools (flange, bend, punch)
  • Curves: 3 tools (line, arc, spline)
  • WAVE / associative: 2 tools (wave link, associative copy)
  • Validation: 2 tools (check geometry, interference check)

Requirements

  • Siemens NX installed (developed on NX 2412)
  • Node.js >= 18
  • .NET Framework 4.8 (Windows)
